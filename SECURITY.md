# Security Policy

## Supported versions

Only the latest release receives security fixes.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Please do **not** report security problems in public GitHub issues.

Send a private message on Telegram to **[@Forhad71](https://t.me/Forhad71)** with:

- a short description of the problem and its impact,
- the steps to reproduce it,
- the extension version and browser version you used.

You can expect a first reply within a few days. Once the issue is confirmed, a fix will be released as soon as possible and you will be credited in the changelog if you wish.

## Scope

Examples of issues worth reporting:

- a web page being able to read data from the extension or trigger its actions,
- the extension sending account data anywhere other than Microsoft or Google Trends,
- permissions being used beyond what the README describes.
